## 地铁站卡片内容：数据源调研（产出 station-data-plan.html）
用户问「有没有现成的每站打卡清单数据」+ UGC 后端 + 艾宾浩斯 + 线路收集模式。实测结论：
- **没有现成的**「地铁站→值得逛的点」粒度中文公开数据集。
- OSM Overpass 实测可用：北京地铁站 427 条/南京 294 条，站名匹配率 **89.5% / 85.0%**；
  坐标已存 `_osm_stations_beijing.json` / `_osm_stations_nanjing.json`。
- **冷站悖论**：热门站富（天安门东 25 条、菜市口 12 条、南锣鼓巷 11 条），冷站空（朱辛庄 0 条）。
  而用户要的恰是冷门历史现场 → 只能靠文保名录 + UGC。
- Overpass 工程坑：全市单查必 504，需 4×4 分片 + 镜像轮询 + 重试 + 去重（实测 16 片败 8 片，
  且败的正好是主城区）；噪声大（世界公园微缩景观 Abu Simbel 被当 POI）。
- **License 硬约束**：高德/百度 POI 禁止离线存储与再分发 → 只能运行时调用，不能烘焙进单文件
  GitHub Pages 产物。OSM(ODbL)/Wikidata(CC0) 可分发。
- 其他源：文保单位 5058 处空间数据集（geodata.cn，含 shp+xls，专补冷站，待下载）；
  Wikidata SPARQL 可用；china_subway(GitHub) 只有站名无坐标；Foursquare OS Places 中国覆盖差。
- 定案建议：四层叠加（OSM 事实 / 文保权威 / LLM 草稿 / UGC），每条内容带来源标记。
- 艾宾浩斯建议：**记忆等级做成收集的第二维度**（铜银金钻），不要做打断式弹窗；
  复习最小单位拆成「可判对错的一条事实」；触发走"局内发光+吃到弹回忆卡" + 局外快速问答；
  间隔按真实时间（1/3/7/21 天）。
- 线路收集建议：徽章(A) + 线路专精等级(B) 叠加，暂不做枢纽任务(C)/赛季(D)。
- 遗留待用户拍板：先铺全量数据还是先做 20 站小样本 / 接不接高德 / 冷站要不要下文保数据集。
- 站序校准前置：南京 6 号线官方 19 站 vs 项目 20 站，另有 8 条线站序未抽查。

## 全量数据生产（用户拍板：铺全量 / 高德贵吗 / 冷站要下）

### 高德定价（官方 lbs.amap.com/home/package）
- 基础搜索服务（关键字/周边/多边形/ID/输入提示）**30 元/万次 = 0.003 元/次**。
- 月配额：个人认证 **5,000 次**、企业认证 50,000 次（基础搜索服务）。
- 铺 676 站一次快照约 700–2000 次 → **免费额度够用**，超了也就几块钱。
- **所以不贵；真正障碍是条款禁止离线存储/再分发 → 只能运行时调用，不能烘焙进单文件。**

### 产出（脚本可复用）
`fetch_station_poi.js <city>` → `build_station_cards.js <city>` → `gen_preview.js`
- 坐标：OSM 直接匹配 + **同线相邻站插值**兜底（地铁间距均匀，误差可接受）。
  北京 410 站 = OSM 367 + 插值 27 + 端点退化 16；南京 266 = 226 + 38 + 2。**零缺失**。
- **按线路分组抓 POI 比网格分片好得多**：一条线的站围出的 bbox 小且贴合分布，
  Overpass 不易超时。线内再按站数切 ≤6 段。每片结果落 `poi_cache/`，失败可单线重跑。
- Overpass 限流严重：北京跑 3 轮（22→20 失败）、南京 3 轮（31→23→18），
  收益递减后停手。**顽固失败集中在 3 号线、17 号线、S2/S4/S6/S7 —— 后续可择机补跑。**
- 文保走 **Wikidata SPARQL**（CC0，可内置）：北京 177 条 / 南京 88 条。
  关键：北京用 `P131* wd:Q956`，南京 QID 是 **Q16666**（不是 Q166659，后者返回 0）。
  `geof:latitude` 做 bbox 过滤会 502/超时 —— **别用地理函数，用实体链或本地 bbox 过滤**。

### 结果
| 城市 | 站数 | 有 OSM | 有文保 | 有内容 | 空白 |
|---|---|---|---|---|---|
| 北京 | 410 | 315 | 99 | **318 (77.6%)** | 92 |
| 南京 | 266 | 97 | 53 | **109 (41.0%)** | 157 |
| 合计 | 676 | — | 152 | **427 (63.2%)** | 249 |

- **文保确实补冷站**：南京 22 个 OSM 空白站被补上（栖霞山/下马坊/雨花门/钟灵街/八卦洲大桥南/金陵石化…），
  北京 3 个（果园/车公庄西/景风门）。这验证了「文保名录专补冷门」的判断。
- 南京覆盖率低不是数据缺失，是客观现实：空白站多为江宁/仙林/浦口新兴居住区，本来就没什么可逛。
- 剩余空白站的兜底：项目已有 CARDS 覆盖其中 8 个、HISTORY 覆盖 21 个（北京）。
- 噪声提醒：OSM 的 `artwork`（现代雕塑）质量差（"映像自我""Loving Couple""菜鸟驿站"），
  入卡时应降权或过滤。
