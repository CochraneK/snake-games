# 苏络贪吃蛇 · Su Luo Snake

一个以文字为蛇身的贪吃蛇小游戏：蛇身由「苏」「络」二字交替连成，吃下的食物也是「苏」「络」二字。

## 特性
- 🐍 蛇身即文字：每一节身体显示一个「苏」或「络」，连起来就是「苏络苏络……」
- 🍎 食物也是字：随机生成「苏」或「络」，吃到即变长
- ⌨️ 多端操控：方向键 / WASD，移动端可滑动屏幕，并提供屏幕方向键
- ⏸️ 空格暂停 / 继续，得分与最高分本地保存
- 🎨 宣纸水墨 + 青色中国风配色，单文件零依赖

## 玩法
打开 `index.html` 即可游玩：
- 用方向键 / WASD / 滑动控制蛇的移动方向（不能 180° 掉头）
- 蛇头撞到边界或自身即游戏结束
- 吃一个食物得分 +1，并略微加速

## 运行
直接用浏览器打开 `index.html`，无需任何依赖或服务器。

```bash
# 本地预览（可选）
python3 -m http.server 8080
# 然后访问 http://localhost:8080
```
