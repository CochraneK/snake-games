# 苏络贪吃蛇 · 开放世界版

一个以文字为蛇身的开放世界贪吃蛇：蛇身由「苏」「络」二字交替连成，吃下的食物也是「苏」「络」二字。
地图很大、相机始终跟随你、有多条 AI 蛇一起抢食竞争，**不会被撞死**——只管追着食物吃，比谁更长。

## 特性
- 🐍 蛇身即文字：每一节身体显示一个「苏」或「络」，连起来就是「苏络苏络……」
- 🍎 食物也是字：地图上常驻 ~110 个「苏」「络」，吃到即变长
- 🌍 开放大地图：60×60 世界，相机跟随，右下角有世界缩略图
- 🤖 多蛇竞争：6 条 AI 蛇（赤/橙/碧/蓝/紫/黛）同时抢食，实时排行榜
- 🛡️ 不撞死：撞到别的蛇身只是这一拍被挡住，不会结束
- 📱 手机适配：响应式画布 + 滑动控制 + 屏幕方向键，支持触屏
- ⌨️ 方向键 / WASD / 空格暂停，最高分本地保存
- 🎨 宣纸水墨 + 青色中国风，单文件零依赖

## 玩法
直接用浏览器打开 `index.html`：
- 方向键 / WASD / 滑动屏幕控制方向（不能 180° 掉头）
- 相机自动跟随你，去食物多的地方抢食
- 和对手比长度，登顶排行榜第一名
- 撞到别的蛇不会死，只是暂时被挡

## 运行
```bash
# 直接打开
open index.html        # macOS
# 或本地起服务预览
python3 -m http.server 8080   # 访问 http://localhost:8080
```
