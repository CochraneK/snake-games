# 苏络贪吃蛇 · 开放世界

以文字为蛇身的开放世界贪吃蛇：蛇身是一条「苏络苏络…」的字链，吃的是「苏」「络」发光豆子。
大地图、相机跟随、多蛇抢食，**两种死亡规则可切换**。

## 贪吃蛇大作战机制对照

| 机制 | 大作战（slither.io 同源） | 本作实现 |
|---|---|---|
| 计分 | 长度即分数，光点越大长得越多 | 同：长度=分数；小豆 +1，掉落大豆 +3 |
| 能否穿过别人身体 | **不能**，撞到就死 | 同：不能穿过（撞上即被挡住） |
| 撞到别人身体 | **死亡** | 双模式：开放世界=掉 3 节肉；大作战=死亡 |
| 死亡/掉肉后 | 尸体散成光点，被别人抢吃快速变长 | 同：掉的肉变大豆子，谁抢到谁长 |
| 加速 | 消耗自身长度换速度，用于截杀/突围 | 同：Shift 或「加速」按钮，消耗长度（掉的肉也会被抢） |
| 击杀收益 | 吃对手残骸暴长 | 同：抢大豆子快速变长 |
| 边界 | 撞墙死亡 | 无墙：64×64 环绕世界，走到头从另一侧出来 |

**两种模式**（开局 toolbar 或底部按钮切换）：
- **开放世界**（默认）：撞到别人身体 → 掉 3 节肉变豆子，不死，继续玩
- **大作战**：撞到别人身体 → 死亡，全身散成豆子被抢，可重新开始（AI 蛇 2.5 秒后自动重生）

## 防眩晕 & 屏幕
- **相机死区**：你在中心 ±2 格内移动时**地图完全不动**，只有蛇在动；超出才平滑推动相机
- **格间插值渲染**：逻辑 150ms 一步，但渲染用 rAF 在两格之间平滑插值，蛇是滑行而非「跳格」（原先每秒整图抽搐 7 次是眩晕主因）
- **相机 lerp 跟随**：相机以 0.16 系数平滑趋近，不再瞬移
- **视野自适应**：按屏幕宽度自动决定视野格数（15–30 格），桌面最大 760px
- **全屏模式**：点「全屏」隐藏所有 UI，画布撑满 `100vmin`，视野最大化

## 视觉区分（不再误撞）
- **蛇**：连续粗链（深色描边 + 蛇色填充）+ 圆头 + **两只眼睛** + 名字标签；玩家蛇额外有金色外圈
- **食物**：孤立的**圆形发光豆子**（朱砂渐变 + 白色描边 + 光晕），中间的「苏」「络」比蛇身字小得多
- 形状（链 vs 圆点）+ 颜色（青/彩色 vs 朱砂）+ 光晕 三重区分

## 操作
- **手机**：在画面**任意位置按住拖动 = 虚拟摇杆**（全屏范围，不是固定小圈，已移除方向键盘）
- **电脑**：方向键 / WASD / 鼠标拖动
- **加速冲刺**：**连按两次方向键**（电脑）/**连点两下画面**（手机）→ 冲刺 1.2 秒，速度翻倍但**每 6 步掉 1 节肉**，肉落地成豆子会被抢（也可长按「加速」按钮）
- **空格**：暂停 · 点「全屏」按钮进入全屏
- 排行榜实时显示 7 条蛇长度与排名；右下角为世界缩略图（含视野框）

## 全屏：横屏真·铺满
全屏时画布铺满**整个视口**（`100vw × 100vh`），视野是**矩形**的——横屏时横向看得更远，不会像正方形那样只占中间一块。每格固定 30px，视野行列数按视口实际尺寸算（横屏 800×400 → 约 26×13 格）。

## 难度：刻意做得轻松（爽点）
核心是「**撞到不会死，只掉 3 节肉**」——掉的肉会变成大豆子，谁抢到谁赚。对手被刻意调笨：

| 对手削弱项 | 参数 |
|---|---|
| 与玩家**同速** | `BOT_SKIP=1`（改 2 则对手半速）|
| 迟钝（每 4 拍才重新决策） | 其余时间直行，会绕远、错过转弯 |
| 近视（只看得见 12 格内的豆子） | 不会精准奔向远处大豆子 |
| 失误率 7% | 会乱转 |
| 起步更短 | 对手 5 节 vs 玩家 8 节 |
| 豆子更多 | 常驻 170 个 |

对手撞到别的蛇**同样会掉肉**，惩罚对玩家和 AI 是对等的。
