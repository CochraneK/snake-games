# 贪吃蛇合集 · Snake Games

同一个开放世界贪吃蛇**引擎**，多个「蛇」版本。当前内置：

- **苏络**（`?theme=su`）：蛇身是「苏络苏络…」文字链，吃「苏」「络」发光豆子
- **CC**（`?theme=cc`）：蛇身是「CcCc…」文字链，给另一个人用的同款
- **北京地铁**（`?theme=beijing`）：每条蛇是一条**地铁线路**（颜色=线路色），食物是车站

大地图、相机跟随、多蛇抢食，**两种死亡规则可切换**。想加新版本只改一处配置，见下文「加一个新版本」。

## 怎么玩 / 链接

- 版本列表（发给别人用这个）：`index.html` → https://cochranek.github.io/snake-games/
- 直接进某个版本：
  - 苏络：https://cochranek.github.io/snake-games/play.html?theme=su
  - CC：https://cochranek.github.io/snake-games/play.html?theme=cc
  - 北京地铁：https://cochranek.github.io/snake-games/play.html?theme=beijing
- 不写 `?theme` 时默认 = 苏络。

## 贪吃蛇大作战机制对照

| 机制 | 大作战（slither.io 同源） | 本作实现 |
|---|---|---|
| 计分 | 长度即分数，光点越大长得越多 | 同：长度=分数；小豆 +1，掉落大豆 +3 |
| 能否穿过别人身体 | **不能**，撞到就死 | 同：不能穿过（撞上即被挡住） |
| 撞到别人身体 | **死亡** | 双模式：开放世界=掉 3 节肉；大作战=死亡 |
| 死亡/掉肉后 | 尸体散成光点，被别人抢吃快速变长 | 同：掉的肉变大豆子/车站，谁抢到谁长 |
| 加速 | 消耗自身长度换速度 | 同：连点两下/双击方向键冲刺，消耗长度（掉的肉也会被抢） |
| 边界 | 撞墙死亡 | 无墙：64×64 环绕世界，走到头从另一侧出来 |

**两种模式**（开局 toolbar 或底部按钮切换）：
- **开放世界**（默认）：撞到别人身体 → 掉 3 节肉变豆子，不死，继续玩
- **大作战**：撞到别人身体 → 死亡，全身散成豆子被抢，可重新开始（AI 蛇 2.5 秒后自动重生）

## 防眩晕 & 屏幕
- **相机死区**：你在中心 ±2 格内移动时地图完全不动，只有蛇在动；超出才平滑推动相机
- **格间插值渲染**：逻辑 150ms 一步，渲染用 rAF 在两格之间平滑插值，蛇是滑行而非跳格
- **相机 lerp 跟随**：相机以 0.16 系数平滑趋近
- **视野自适应**：按屏幕实际尺寸算视野格数（横屏 800×400 → 约 26×13 格）
- **全屏**：画布铺满 `100vw × 100dvh`，**竖屏手机自动转横屏**并铺满，右上角浮层可见排行榜

## 视觉区分（不再误撞）
- **蛇**：连续粗链（深色描边 + 蛇色填充）+ 圆头 + 两只眼睛 + 名字标签；玩家蛇额外有金色外圈
  - 文字版：蛇身每节叠一个字（如「苏」「络」）
  - 地铁版：线路色粗线 + 中间白色虚线（像轨道），头上是线路名（如「1号线」）
- **食物**：
  - 文字版：孤立的圆形发光豆子（朱砂渐变 + 白色描边 + 光晕），中间的字比蛇身字小
  - 地铁版：白色小方块「车站」标记
- 形状 + 颜色 + 光晕三重区分

## 操作
- **手机**：画面任意位置按住拖动 = 虚拟摇杆；连点两下画面 = 加速冲刺
- **电脑**：方向键 / WASD / 鼠标拖动；连按两次方向键 = 加速冲刺；空格暂停
- 排行榜实时显示 7 条蛇长度与排名；右下角为世界缩略图（含视野框）

## 托管模式（AI 代打 + 无敌）
点画面左上「托管」按钮：玩家蛇交给 AI（每拍决策、全图视野、不失误），**无敌**（撞到只被挡住，不掉肉不死亡）。动一下方向键 / 摇杆即自动接管回来。

## 难度：刻意轻松（爽点）
核心是「撞到不会死，只掉 3 节肉」。对手被刻意调笨：与玩家同速、迟钝（每 4 拍才决策）、近视（只看得见 12 格内豆子）、7% 失误率、起步更短（5 节 vs 玩家 8 节）、豆子更多（常驻 170 个）。对手撞到别的蛇同样会掉肉，惩罚对等。

## 加一个新版本（不用改引擎）
1. 在 `play.html` 的 `THEMES` 里加一项。文字蛇：
   ```js
   xx: {
     id:"xx", label:"XX", kind:"text",
     title:"XX 贪吃蛇 · 开放世界", foot:"XX · Snaker",
     chars:["X","x"], foodChars:["X","x"],
     playerName:"你·XX", botNames:["小X","阿x","X哥","x妹","XX君","X姐"],
     playerColor:"#1f6f6b",
     botColors:["#c0563a","#7a5cc9","#3a8fc0","#c9a23a","#3ac97a","#c93a8f"],
     intro:"吃<b>发光豆子</b>变长……（照抄其它项的写法）",
     bestKey:"xx_best"
   }
   ```
   地铁线（每条蛇一条线）：把 `kind:"text"` 换成 `kind:"metro"`，用 `lines:[{name,color},...]` 代替 `chars/botNames/botColors`，其余照抄。
2. 在 `index.html` 的 `MENU` 里加一张卡片：`{id:"xx", label:"XX", kind:"text", color:"#1f6f6b", desc:"……"}`。
3. 链接：`play.html?theme=xx`。

## 运行
零依赖。直接用浏览器打开 `index.html`（版本列表）或 `play.html?theme=su`。或本地起服务：
```bash
python3 -m http.server 8080   # 访问 http://localhost:8080
```
